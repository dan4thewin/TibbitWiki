TibbitWiki uses Markdown Links to other tiddlers use CamelCase wikiwords. A link to NonExistentPage shows as missing.

Inline code looks like go test ./... and blocks:

func main() {
    fmt.Println("hello TibbitWiki")
}

This is a blockquote — used for callouts and asides.
